# Strangersbuddies

Group trips for people aged 18 to 25 who have never met. Come as strangers, return as buddies.

Live at https://strangersbuddies.github.io. Founded and hosted by Deepansh Deep and Abhay Vimal. Instagram: [@strangersbuddies13](https://www.instagram.com/strangersbuddies13/).

This branch holds the built site. The source (Astro) lives with Deepansh Deep's website, in `sb-src/` and `src/components/sb/`, built with `npm run build:sb`.
